4 · Guide — where files live & what to do with them

General workflow: find your current bindings file below → load it in step 1 → export in step 2 → install the export using the same section → verify in-game before deleting anything. Always keep a backup of the original file.

Elite Dangerous (.binds)

Find yours: %LOCALAPPDATA%\Frontier Developments\Elite Dangerous\Options\Bindings\ — files like Custom.4.0.binds. The game writes one automatically whenever you change a binding; the in-game Controls dropdown shows the PresetName from inside the file.

Install this tool's export: save Unified.4.0.binds into that same folder, launch Elite, open Controls, and pick “Unified” from the preset dropdown.

Gotcha: the stick name field in step 2 must exactly match your hardware's Device string (open your current .binds and copy the Device="…" value, e.g. VKBsim Gladiator). Wrong name = stick inputs silently dead.

Star Citizen (layout_*_exported.xml)

Find/export yours: in-game go Options → Keybindings → Advanced Controls Customization → Control Profiles → Save Control Settings. It lands in <install>\StarCitizen\LIVE\USER\Client\0\Controls\Mappings\ as layout_<Name>_exported.xml.

Install this tool's export: copy layout_Unified_exported.xml into that Mappings folder, open the in-game console (~ key) and run pp_RebindKeys Unified.

Gotchas: set the joystick index in step 2 to match your stick (js1, js2…). If Windows reorders your sticks, fix it in-game with pp_resortdevices joystick 1 2 and list devices with i_DumpDeviceInformation.

No Man's Sky (TKGAMESETTINGS.MXML)

Find yours: Steam: <steam>\steamapps\common\No Man's Sky\Binaries\SETTINGS\TKGAMESETTINGS.MXML (GOG: same tail under your GOG Games folder). Back it up first — a malformed file makes the game regenerate defaults and wipe your remaps. Some pilots set the file read-only after editing so the game doesn't overwrite it.

Install this tool's export: remap at least one key in-game first (so the file has a KeyMapping2 block), then replace that block with the exported one.

Gotchas: NMS has no key chords (a Shift+G export keeps only the modifier) and limited stick support — flagged rows must be rebound in-game under Remap Controls.

Reading the table

“exact” = same concept in every game. “approx” = closest equivalent, hover/tap for why (e.g. Silent Running → G-force safety). Unmapped rows are dimmed — the export leaves them unbound rather than guessing.

The crosswalk lives in data.js — if you know a better equivalent for your ship, edit it there and reload.

Static single-page app — no server, your files never leave the browser. Built for HOTAS/HOSAS pilots who want one muscle memory.
